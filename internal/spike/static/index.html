    Now the real test: offline

    1. Wait until every check above has finished.
    2. Turn on airplane mode and then turn Wi-Fi back on only if you want the node reachable; for the cleanest test, stop the node instead (Ctrl-C on the laptop) so nothing can answer.
    3. Reload this page, or open it from the browser's history.
    4. If it loads and says OFFLINE LOAD below, the service worker served it from the phone's own storage.
    5. Reconnect and reload once: the page sends the result to the node by itself.
